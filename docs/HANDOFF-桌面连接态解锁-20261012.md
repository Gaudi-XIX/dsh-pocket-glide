# HANDOFF — 桌面配对页连接态解锁（2026-10-12 01:1x）

## 0. 用户原话（两条，加一条通则）

> 1. Pocket 的电脑端连接后会锁死，不要锁死。举个例子，我连接了之后，如果突然想提前把
>    Cloudflare 的固定地址填好，就过不去了。
> 2. 我记得好像连接手机以后，在「设备与消息」那一页，手机连接成功的提示把消息提醒给遮掉了，
>    就看不到了。反正我的意思是告诉你，不要增加这种额外的限制。主要是它没有解决什么痛点，
>    **一切以解决痛点为核心**。

通则已另记入工作区 AGENTS.md「约定」，不在本档展开。

## 1. 根因（三条，都不是安全约束）

| # | 症状 | 实因 | 位置 |
|---|---|---|---|
| R-1 | 连上后填不了 Cloudflare 固定地址 | **两重**：① 「局域网」「公网」两个键按 connected 上了 `disabled`（模板插值 + `syncModeControls(connected)` + `switchMode` 里 `if(phoneConnected…)return`，三处同一意思）；② 更致命——`#tunnelConfigPanel` 嵌在 `#deviceExtras` 里，它自己的 `.show` 只在 **tunnel 视图**开，父容器的 `.show` 只在 **devices 视图**开，两者互斥 ⇒ **任何状态下都打不开**。这条把「待你裁决」第 4-② 项（I-13 隧道配置无 UI 回退路径，hostname 只能手删 settings 文件）判成了真 bug，且比原描述更严重：不只是连接态进不去 | `lib/pages.js` 桌面页模板/CSS/脚本 |
| R-2 | 连接成功提示遮住消息提醒 | `.phone-connected .pairing-content{display:none}` 按**连接态**把整块配对区隐藏，而「待确认接入」`#pendingPairings` 是 `.pairing-content` 的后代 ⇒ 绿色「手机已连接」卡出现即把它一起带走。第二台手机请求配对时看不见、也点不到允许 | 同上 |
| R-3 | 同类隐患（未列症状） | devices 视图靠**四条**子元素规则（`.qr`/`.url-row`/`.expires`/`#pinPanel`）逐个隐藏配对内容；每加一个子元素都要记得补一条，漏了就漏进设备视图。R-2 正是这类「按状态整块隐藏」与「按子元素逐个隐藏」混用的产物 | 同上 |

**关键判据（决定这不是「放宽安全边界」）**：桥侧早就写明了。`/desktop/tunnel/toggle` 的注释（`lib/bridge.js:3407`）——
「A live phone is not a reason to refuse: switching modes used to be blocked whenever any session
existed (**M4**)」；`/desktop/tunnel/config`（GET/POST）**从来没有**连接态门禁，只有 desktop 来源校验
与 hostname 形状/长度校验。也就是说服务端在 M4 那一轮已经裁定「连着手机不是拒绝理由」，
**拦住人的只剩页面自己**——R-1 的三重 disabled 与 R-2 的隐藏规则是那次改动没跟上的残留。

## 4. 未做与代价（须暴露）

1. **连接态点另一个模式的键＝真的切隧道**：正走公网的那台手机会掉线。这不是新引入的风险
   （桥侧 M4 已允许），是解除 UI 拦截后**用户会第一次真正看见**的行为。判「要不要再兜一层」之前先看
   通则：兜一层就是再加一条不解决痛点的限制。GUI-CHECKLIST 12-④ 已把它写成目验项。
2. **落地默认视图没改**：连接后仍落在 devices 视图（`modeView = options.connected ? 'devices' : 'tunnel'`）。
   痛点是「进不去」，不是「落地位置」；改落地会牵动 `sessionStorage.pocketModeView` 那条已知的
   服务端渲染/客户端变量不一致，按「不扩成一套机制」未动。
3. **版本与 CHANGELOG 未动**（`package.json` 仍 0.4.31 ＝ HEAD `42d4c6b`）。本工作树里另有三条线未提交
   （落地页拥挤／新建对话草稿态／settleOlderShift），`repo-hygiene ⑨` 钉的是「CHANGELOG 最新一节 ＝ version」，
   我单方提到 0.4.32 会把别人的在途活计一起标成我的版本。**发版那一步须由收口的人一次做完**，本文即可直接贴：

